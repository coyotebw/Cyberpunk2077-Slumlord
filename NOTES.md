## Build

Requirements: Python 3 (stdlib only), WolvenKit CLI 10.0.0-beta.1 (.NET 10):
`dotnet tool install -g WolvenKit.CLI --version 10.0.0-beta.1` → `cp77tools`.

```
tools/quest/build_scenes.sh                              # generate quest files, convert to CR2W, move into the archive tree
cp77tools pack wolvenkit/source/archive -o build         # -> build/archive.archive
mv build/archive.archive build/Slumlord.archive
```

Two packs of the same files differ only in the archive's file-table timestamps.
PNG → `.xbm` import works only in the WolvenKit GUI on Windows (`TEXG_Generic_UI`).

Script check: redscript 0.5.32. Compile errors show in `r6/logs/redscript_rCURRENT.log` at game start. A
standalone check with `redscript-cli compile` needs the Codeware, TweakXL and Audioware `.reds` sources (`-s`)
and the vanilla bundle (`-b`). The only expected warning is Codeware's `Reflection.reds` "not all code paths
return a value".

## How the encounters work

Both encounters are native quest phases added under `cyberpunk2077.quest` by ArchiveXL (`quest: phases:`).
Each root phase loops: wait (ready fact, V inside the trigger area, game free) → run the encounter in an inline
phase → clean up (despawn, unblock, reset facts) → wait again. Scripts and phases talk through facts. The full
list is in the `make_scenes.py` docstring (`slumlord_<key>_ready/scene/fight/won/abort/tries`, `fc` = harbor,
`co` = motel). Casts come from communities in AlwaysLoaded mod sectors. Vanilla V lines are referenced by
string id (motel). The harbor V line is custom because the vanilla line needs Phantom Liberty.

`slumlord_gate.questphase` keeps `slumlord_game_free` up to date for the debug readouts only. Calls and texts
don't wait on it: it read "busy" the whole time V was buying at a computer.

## Toolchain gotchas

- WolvenKit 10.0.0-beta.1 writes a NodeRef given as a uint64 hash as 0. Vanilla node refs must be written as
  path strings (`qgraph.NR` rejects ints). To find a path: NodeRef hash = FNV-1a 64 of the path with `#`
  removed, matched against the hash list; a compiled area's `debugName` (e.g. `{cs_patrol_com}_044`) names its
  node.
- Uninstalling mid-encounter leaves the content tokens blocked (`slumlord_co` / `slumlord_fc`) and the motel's
  NCPD patrol off. End the encounter (walk away) before uninstalling.
